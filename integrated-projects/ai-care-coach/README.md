# AI Care Coach

基于 Next.js 的医学、心理、艺术与身心疗愈整合展示页面。

## 快速开始

```bash
npm install
npm run dev
```

## 功能

- 交叉联系地图
- 精神能量与身心节律护理疗愈模块
- 《天纪》八卦图像与医易道知识图谱
- 终极智慧辨析
- 自我状态判断
- 伦理应用心法

## 文档

详尽指南已存放在 `docs/readme.md`，包含：

- 意识自由纵轴
- 实践金字塔
- 伤害、滋养与恢复
- 中国大陆地区能量趋势分析

## 部署

1. 将仓库推送到 GitHub：

```bash
git push origin main
```

2. 在 Vercel 中创建新项目，选择该 GitHub 仓库。
3. 使用默认设置部署 Next.js 应用。

Vercel 会自动识别 `package.json` 和 `next.config.js`，并完成构建与发布。

# 医药信息工程 · 第 3 周

> 目标：加入搜索、筛选和基础交互，让医药信息工具从展示页变成可用工具。

## 本周主题

搜索筛选 + 交互状态 + 可用性。

## 每周任务

- 增加关键词搜索：支持按名称、分类、摘要检索。
- 增加分类筛选：药品、疾病、检查、指南或科室。
- 增加空状态：没有结果时给出清楚提示。
- 增加错误状态：数据加载失败时不让页面空白。
- 记录一次用户使用路径：用户如何从搜索到找到信息。

## 软件工程实践

- 把搜索逻辑和渲染逻辑拆开。
- 给边界情况做手动测试：空关键词、无结果、特殊字符、移动端。
- GitHub 提交记录体现功能拆分。

## 输出作品

- 可搜索的医药信息工具。
- 一份交互验收清单。
- 一次 Vercel 部署记录。

## 验收标准

- 搜索和筛选可以组合使用。
- 空状态、错误状态有明确反馈。
- Vercel 线上版本与本地版本一致。

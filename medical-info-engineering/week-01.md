# 医药信息工程 · 第 1 周

> 目标：建立医药信息产品的工程底座，完成一个能部署、能说明、能迭代的项目入口。

## 本周主题

医药信息产品认知 + 软件工程交付流程。

## 每周任务

- 明确一个医药信息场景：药品说明书查询、用药提醒、疾病知识卡片、临床指南摘要或医院科室导航。
- 写出目标用户、使用场景、核心问题和不可做的边界。
- 建立 GitHub 仓库目录：`README.md`、`docs/`、`src/`、`public/`。
- 部署一个静态首页到 Vercel。
- 在 README 中记录 GitHub 链接、Vercel 链接和本周复盘。

## 软件工程实践

- 每天至少 1 次提交。
- 提交信息说明真实意图。
- 每次部署后检查首页、移动端、链接和文本是否正常。

## 输出作品

- 医药信息工程主页 v1。
- 一页项目说明 README。
- 一条可访问的 Vercel 链接。

## 验收标准

- 用户打开首页后能知道这个项目解决什么医药信息问题。
- GitHub 上能看到连续提交记录。
- Vercel 页面可公开访问。

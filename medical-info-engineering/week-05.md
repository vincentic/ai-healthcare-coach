# 医药信息工程 · 第 5 周

> 目标：把医药信息工具升级为一个有版本、有反馈、有迭代记录的小产品。

## 本周主题

反馈闭环 + 版本发布 + 项目管理。

## 每周任务

- 增加反馈入口：可复制反馈模板或简单表单。
- 建立版本日志：记录 v0.1、v0.2、v0.3 的变化。
- 用 GitHub Issue 或 Markdown 清单管理需求。
- 挑选 3 个用户场景做可用性检查。
- 根据反馈完成一次小迭代。

## 软件工程实践

- 每个版本对应一个清楚提交或 tag。
- 每次迭代写清楚：问题、方案、验证结果。
- 避免一次提交混入太多无关修改。

## 输出作品

- 带反馈入口的医药信息工具。
- 版本日志。
- 需求与问题清单。

## 验收标准

- 用户知道如何反馈问题。
- GitHub 能看出每个版本改了什么。
- Vercel 上线版本对应最新提交。

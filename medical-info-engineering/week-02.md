# 医药信息工程 · 第 2 周

> 目标：把医药信息内容从零散资料整理成结构化数据，并用页面展示。

## 本周主题

医药信息结构化 + 前端数据展示。

## 每周任务

- 选择 10 条医药信息样本，例如药品名称、适应症、禁忌、不良反应、注意事项。
- 设计一份 JSON 数据结构。
- 完成列表页：支持展示名称、分类、核心摘要和风险提醒。
- 完成详情页或详情区域：展示完整字段。
- 在 README 中说明数据来源、字段含义和使用限制。

## 软件工程实践

- 用小提交推进：数据结构、列表展示、详情展示、样式优化分开提交。
- 每次改字段后检查页面是否仍能渲染。
- 不把医药内容写成诊疗建议，保留“仅作信息学习”的边界。

## 输出作品

- 医药信息列表页。
- 一份结构化 JSON 数据。
- 数据字段说明文档。

## 验收标准

- 至少 10 条信息可以正常展示。
- 字段命名清晰，后续能继续扩展。
- 页面在手机宽度下不溢出。

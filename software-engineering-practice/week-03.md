# 软件工程实践 · 第 3 周

> 目标：把小工具升级成可保存数据的清单工具，练习数据结构、筛选搜索和本地持久化。

## 本周主题

数据结构 + 搜索筛选 + localStorage。

## 每周任务

- 为每条数据设计字段：标题、分类、状态、优先级、创建时间或备注。
- 完成新增、编辑、删除和状态切换。
- 加入搜索、分类筛选或状态筛选。
- 使用 `localStorage` 保存数据，刷新页面后仍能恢复。
- 补齐数据为空、搜索无结果、保存失败时的提示。

## 工程实践

- 把数据更新逻辑集中管理，减少重复 DOM 操作。
- 为关键状态写手动验收清单。
- 每次改数据结构时同步更新 README 或复盘记录。

## 每步更新 GitHub / Vercel

- 开始前：在 GitHub 记录数据字段设计和验收清单。
- 完成数据结构或持久化：提交并推送到 GitHub，说明字段或存储逻辑变化。
- 完成搜索筛选：部署 Vercel 预览，验证刷新、筛选和无结果状态。
- 收尾时：把 GitHub 链接、Vercel 链接、字段设计和验收结果写进复盘。

## 输出作品

- 一个可保存数据的清单工具。
- 一份字段设计说明。
- 一份功能验收记录。

## 验收标准

- 刷新页面后数据不会丢失。
- 搜索和筛选结果符合预期。
- 删除、编辑、清空等操作不会导致页面异常。

# 软件工程实践 · 第 2 周

> 目标：做出一个真正可用的工具型单页应用，练习把页面结构、交互状态和响应式布局组合成完整体验。

## 本周主题

HTML/CSS/JS + 响应式布局 + 表单状态。

## 每周任务

- 选择一个小工具主题：待办清单、学习打卡、链接收藏、预算记录或关键词整理。
- 画出页面结构：输入区、列表区、筛选区、空状态和操作按钮。
- 用 HTML/CSS 完成桌面和手机布局。
- 用 JavaScript 完成新增、删除、勾选、清空或筛选等核心交互。
- 为表单补齐必填校验、空状态提示和操作反馈。

## 工程实践

- 先完成最小可用版本，再补样式和边界状态。
- 每完成一个交互就提交一次。
- 部署后在手机宽度下检查按钮、输入框和长文本是否溢出。

## 每步更新 GitHub / Vercel

- 开始前：在 GitHub 写清楚工具主题、用户场景和本周任务。
- 完成一个交互：提交并推送到 GitHub，例如新增、删除、筛选各自独立提交。
- 完成可用版本：部署到 Vercel，检查输入、按钮、空状态和移动端布局。
- 收尾时：在 README 或复盘中更新 GitHub 提交记录、Vercel 链接和已知问题。

## 输出作品

- 一个工具型单页应用。
- 一段功能说明和使用场景。
- 一条部署链接和本周复盘。

## 验收标准

- 用户不看说明也能完成主要操作。
- 输入为空、列表为空、内容很长时页面仍然可用。
- 桌面和手机宽度下布局都不混乱。

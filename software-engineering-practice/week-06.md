# 软件工程实践 · 第 6 周

> 目标：把前 5 周的练习整理成软件工程实践作品集，让作品、过程、链接和复盘都能被快速查看。

## 本周主题

首页导航 + 项目说明 + 截图 + 部署链接。

## 每周任务

- 整理已有作品：学习主页、工具页、清单工具、迭代版本和发布记录。
- 为每个作品补齐说明：解决什么问题、用了什么技术、你做了什么取舍。
- 在首页增加作品集入口和清晰导航。
- 为每个作品补充 GitHub 链接、部署链接和截图说明。
- 写一份 6 周总复盘：能力变化、最大卡点、下一阶段计划。

## 工程实践

- 把作品说明写给“第一次打开的人”看。
- 链接、截图和说明保持一致。
- 部署前完成完整的桌面和手机宽度检查。

## 每步更新 GitHub / Vercel

- 开始前：在 GitHub 汇总前 5 周作品、提交记录和待补链接。
- 每整理一个作品：提交并推送说明、截图、GitHub 链接和部署链接。
- 完成作品集首页：部署到 Vercel，检查导航、截图、外链和移动端。
- 收尾时：把最终 GitHub 仓库、Vercel 生产链接和 6 周总复盘放到首页或 README。

## 输出作品

- 软件工程实践作品集。
- 一份 6 周总复盘。
- 一组可展示的 GitHub 和部署链接。

## 验收标准

- 打开首页后能找到软件工程作品集。
- 每个作品都有清楚说明和可访问链接。
- 复盘能说明你从需求拆分到部署上线的完整工程能力。

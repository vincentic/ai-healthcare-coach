# 输入-输出-反思飞轮：价值创造导向模块

本文基于 `docs/value.md`，将语言学习从“掌握表达”升级为“创造可交付价值”。系统不只帮助用户学会一门语言，还帮助用户把多语学习、跨文化困惑、自我认同经验，转化为文章、课程、咨询、社群和个人方法论。

## 核心价值主张

用户获得的不只是语言能力，而是三种可复用能力：

- 视角转换：理解同一事件在不同语言和文化脚本中的不同含义。
- 整合力：把多语身份、局外人感、文化差异转化为稳定表达。
- 桥梁能力：帮助自己和他人跨越语言、文化、身份和情境误解。

产品的长期方向：

```text
语言学习工具 -> 跨文化 mentoring 系统 -> 价值创造工作台
```

## 飞轮模型

```text
输入 -> 输出 -> 反思 -> 产品化 -> 反馈 -> 强化输入
```

### 1. 输入

输入不是被动吸收材料，而是收集原料。

输入来源：

- 语言材料：高频词、实用短语、Shadow Reading 音频、方言表达。
- 文化材料：误解、冲突、礼貌差异、职场脚本、家庭沟通脚本。
- 身份材料：多语切换时的自我变化、局外人感、碎片化感受。
- 真实案例：用户自己的跨文化沟通事件、留学/移民/工作困惑。

功能模块：

- `Input Inbox`：保存句子、音频、短视频台词、日记片段、文化误解案例。
- `Culture Note`：记录“这句话在另一个文化里为什么不一样”。
- `Dialect Snapshot`：记录方言表达、标准语对照、地区和场景适用性。
- `Identity Journal`：记录“我在这门语言里变成了怎样的人”。

### 2. 输出

输出不是做题，而是创造给别人看的东西。

输出形态：

- 一段目标语表达。
- 一篇跨文化思维笔记。
- 一个多语日记模板。
- 一次情境翻译咨询草稿。
- 一个短视频/播客脚本。
- 一节极简入门课程。

功能模块：

- `Guided Output Studio`：把输入材料转成文章、脚本、课程片段或咨询提纲。
- `Scenario Roleplay`：用真实跨文化场景进行角色扮演。
- `Phrase-to-Product`：把一个短语扩展成“表达解释 + 场景 + 文化提醒 + 练习任务”。
- `Bridge Translation`：不只翻译文字，而是解释语气、关系、权力距离和文化脚本。

### 3. 反思

反思把个人经历转成方法论。

反思问题：

- 这个困惑揭示了什么文化脚本差异？
- 如果换一种语言表达，我的情绪和立场有什么变化？
- 这件事能帮助哪类人少走弯路？
- 它适合变成文章、模板、课程，还是咨询服务？

功能模块：

- `Reflection Prompts`：为每次练习生成复盘问题。
- `Perspective Compare`：比较母语、目标语、方言表达背后的思维差异。
- `Identity Integrator`：把局外人感、碎片感整理成可表达的个人叙事。
- `Lesson Extractor`：从一段经历中提取可教给别人的原则。

### 4. 产品化

产品化是从“我有感受”到“别人能使用”的关键一步。

产品类型：

- 跨文化思维 Newsletter。
- 多语日记/疗愈写作模板。
- 30 分钟情境翻译咨询。
- 极简入门语言课程。
- 方言生存表达包。
- 第三文化/多语心智社群活动。

功能模块：

- `MVP Builder`：把反思内容包装成最小可交付产品。
- `Offer Canvas`：定义目标用户、痛点、承诺、交付物、价格和验证方式。
- `Content Repurposer`：一份反思自动拆成文章、短视频脚本、课程大纲和社群讨论题。
- `Service Script`：为一对一咨询生成开场、诊断、解释、行动建议和复盘模板。

### 5. 反馈

反馈验证价值，也滋养继续学习的动机。

反馈类型：

- 学习反馈：是否听懂、说出、记住、迁移。
- 价值反馈：别人是否收藏、转发、付费、感谢、改变行动。
- 情感反馈：用户是否不再孤独，是否更能理解自己的多语身份。
- 市场反馈：哪类内容、课程或服务最能产生需求。

功能模块：

- `Feedback Ledger`：记录点赞、评论、咨询反馈、收入和用户故事。
- `Impact Review`：把反馈转成“我创造了什么价值”的证据。
- `Next Input Planner`：根据反馈决定下一轮学习、采访或内容主题。

## 模块地图

| 飞轮阶段 | 用户问题 | 功能模块 | 产出 |
| --- | --- | --- | --- |
| 输入 | 我该收集什么？ | Input Inbox, Culture Note, Dialect Snapshot | 语言和文化原料 |
| 输出 | 我怎么表达给别人？ | Guided Output Studio, Bridge Translation | 文章、脚本、对话、咨询草稿 |
| 反思 | 这件事有什么意义？ | Reflection Prompts, Perspective Compare | 方法论、个人叙事 |
| 产品化 | 它如何变成服务？ | MVP Builder, Offer Canvas | 课程、模板、咨询、社群活动 |
| 反馈 | 价值是否成立？ | Feedback Ledger, Impact Review | 证据、收入、下一步主题 |

## 与语言学习模块的关系

`docs/language-mentoring-modules.md` 解决“如何学语言”。本文解决“学语言之后如何创造价值”。

两者连接方式：

- 高频短语库提供表达原料。
- Shadow Reading 提供声音和身体记忆。
- 主动输出模块提供文章、对话、咨询草稿。
- SRS 短语银行沉淀可复用表达。
- 反思飞轮把学习记录转化为作品、服务和社群议题。

## MVP 功能建议

第一版可以只做 4 个模块：

1. `Input Inbox`：保存语言材料、文化事件和身份日记。
2. `Guided Output Studio`：把一条输入转成文章/脚本/咨询提纲。
3. `Reflection Prompts`：自动生成视角转换和身份整合问题。
4. `MVP Builder`：把一次反思包装成可发布的最小作品。

最小用户路径：

```text
记录一次跨文化困惑
-> 选择目标输出：文章/短视频/咨询提纲
-> 回答 3 个反思问题
-> 生成可发布草稿
-> 记录外部反馈
-> 决定下一轮输入主题
```

## 设计原则

- 从真实困惑出发，不从抽象知识点出发。
- 每次输入都要有潜在输出方向。
- 每次输出都要有反思问题。
- 每次反思都要能变成别人可使用的指南。
- 方言和语言变体要保留情境、身份和关系信息。
- 价值创造的证据包括收入，也包括连接、理解和被帮助的故事。
